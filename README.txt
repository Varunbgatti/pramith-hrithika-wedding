Pramith & Hrithika wedding invitation (single file)

index.html        The complete invitation. Open it in any browser, or upload it to any web host as-is.
                  Needs internet only for the Google Fonts (Playfair Display, Montserrat).
art-test/         Optional. The drawing code for the Ganesh ji, lotus, jasmine, leaves, lamp and temple,
                  with preview.html to view them on their own. Everything here is already built into index.html.

To edit details, open index.html and change the block marked "CONFIG: edit here" in the script
(names, map links, date, festivity cards, MUSIC_SRC for an MP3, SONG_URL for a YouTube link).
